# Excel比較グラフ

Excelの**2つの列を比べて**、棒グラフと記録用のExcelを作ります。

## 利用者の頼み方

Excel(.xlsx / .xlsm)を添付して、比べたいものを書いてください。

- 「R7年度とR8年度の入院収入を比較して」
- 「『(1)入院関係の実績』のH列とI列を比較して」
- 「H列とK列を比べて」

**列は見出しの名前でも指定できます。** 「R7年度 / 入院 / 入院収入」のように
見出しが何段かに分かれていても、上の段の名前(年度)と下の段の名前(項目)を
両方書けば、その列を選びます。同じ「入院収入」が年度ごとに何本もある表では、
**年度を書かないと聞き返します**(どれか1つを勝手に選びません)。

**見出しが1行目でなくても読めます。** 表題や注意書きが上に何行あっても、
数値の並びから見出し行を探します。項目名がB列(略称)とC列(正式名)のように
分かれていても、つないで1つの名前にします。

1枚のシートに表が複数あるとき(「(1)入院関係の実績」「(2)外来関係の実績」など)は、
**どの表かを聞き返します。** そのまま書き写せる例も一緒に出します。

## 出てくるもの

| ファイル | 中身 |
|---|---|
| 比較グラフ.png | 項目ごとに2本並べた棒グラフ |
| 比較データ.xlsx | グラフの元になった数値と、差の列。別シートに条件の記録 |

**元になった数値を必ず一緒に返します。** グラフだけを見て判断するのではなく、
数字を確かめられるようにするためです。条件のシートには、元のファイル名・依頼文・
比べた列・作成日時・計算方法を残します。

## このツールがしないこと

**推測しません。**

- 数値の列が3つ以上あるのに指定が無いときは、**勝手に2つ選びません**。
  選べる列を並べて聞き返します
- 項目名(部署名など)が両者で食い違うときは、**勝手に対応づけません**。
  共通する項目だけを比べ、片方にしかない項目は「処理できなかったもの」として報告します
- 全角半角や空白の違いだけは同じ項目として扱いますが、**それ以上は寄せません**

## 計算について

**集計はすべてPythonで行います。ローカルLLMは使いません。**
合計や差の計算をLLMに任せると、合っているかどうかを確かめられなくなるためです。
同じファイルと同じ依頼なら、必ず同じ結果になります。

日本語のグラフは同梱フォント(matplotlib-fontja)で描いています。
隔離環境ではシステムのフォントを読めないため、これが無いと文字が出ません。

## 元のファイル

**変更しません。** 読み取るだけで、結果は新しいPNGとExcelとして返します。

## 分かっている限界

- 同じ列に数値が2行以上続く「表」を探します。数値が飛び飛びの帳票は読めません
- 項目名は、数値の列より左にある文字を全部つないで作ります。
  大項目と内訳が別の列にあっても拾えますが、注記まで拾ってしまうことがあります
- 項目が40件を超えるとグラフが読めなくなるため、先頭40件だけを描きます
  (その旨を補足として返します)
- 項目が12件を超えると、名前を読めるように**横棒のグラフ**へ切り替えます
- グラフからは次を外します。**数値は「比較データ.xlsx」に全件残します**
  - どちらの列も0の項目(棒が出ないため)
  - 「病院全体」「合計」など、名前が合計らしく、かつ他より桁が大きい項目
    (1本だけ伸びて他の差が見えなくなるため)
- 縦持ち(項目が列、期間が行)の表は想定していません

実際の帳票へ当てるときは、**まず1つのファイルで試して**、
出てきた「比較データ.xlsx」が意図どおりか確かめてください。

## 開発者向け

- `resolve_targets` がどの列を比べるかを決めます。決められないときは
  `NeedsUserInput` を投げ、利用者へ選択肢を返します
- `align` が項目名の突き合わせです。**食い違いを黙って捨てません**
- `tests/test_main.py` は「決められないときに聞き返すか」「食い違いを報告するか」を
  中心に確かめています

固めて持ち込む形にするには:

```
python tools/toolpack_pack.py tool-packages/excel_compare_chart
```
