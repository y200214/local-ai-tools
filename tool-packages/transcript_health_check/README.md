# 文字起こし健康診断

会議の文字起こしを**議事録にする前に**、直すべき箇所を洗い出します。

## 利用者の頼み方

Word(.docx)・PowerPoint(.pptx)・Excel(.xlsx / .xlsm / .xls)・字幕(.vtt / .srt)・HTML・テキスト(.txt / .md / .csv など)に対応しています。
**PDFは読めません。** 元のWordやテキストを添付してください(読めない形式のときは、その場で理由と直し方をお返しします)。

添付して、次のように頼んでください。

- 「この文字起こしを診断して」
- 「議事録にする前にチェックして」

## 何を見るか

| 見るもの | なぜ見るか |
|---|---|
| 発言者が分からない行 | 誰の発言か決まらないと議事録にできない |
| 同じ内容の繰り返し | 音声認識で二重に拾われることがある |
| 長すぎて読みにくいかたまり | 確認が難しく、見落としが起きやすい |
| 数値・日時・担当の記述 | **転記ミスが起きやすい箇所**なので目視してほしい |
| 文字化け・記号の乱れ | 元の音声で確認しないと直せない |

結果は2つに分けて返します。

- **処理できなかったもの**: 直さないと議事録にできないもの(発言者不明・文字化け・重複)
- **補足**: 直さなくてもよいが、目を通してほしいもの(長い段落・数値の記述)

## このツールがしないこと

**推測をしません。** 規則で分かることだけを数えます。

- 発言者を推測して補うことはしません(誰の発言かは人が判断してください)
- 「ください/下さい」のような**表記の変種は別物として扱います**。
  無理に寄せると、直す必要のない箇所まで指摘してしまうためです
- ローカルLLMを使いません。同じ入力なら必ず同じ結果になります

指摘が出ても、**それが必ず誤りとは限りません**。直すかどうかは人が決めてください。

## 元のファイル

**変更しません。** 読み取るだけで、結果はチャットへ返します。

## 開発者向け

- 判定の基準は `main.py` の先頭にまとめてあります(`LONG_CHUNK_CHARS` など)
- `tests/test_main.py` は「見つけるべきものを見つける」だけでなく、
  **「見つけてはいけないものを見つけない」**ことも確かめています。
  誤検出が多い診断は使われなくなるためです
- 練習用の架空データは `samples/make_sample.py` が作ります(実データは同梱しません)

固めて持ち込む形にするには:

```
python tools/toolpack_pack.py tool-packages/transcript_health_check
```
