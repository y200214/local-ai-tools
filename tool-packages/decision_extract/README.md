# 決定事項・宿題一覧

会議の文字起こしから、**決定事項**と**宿題(持ち帰り事項)**を抜き出して
Excelの一覧にします。

## 利用者の頼み方

Word(.docx)・PowerPoint(.pptx)・Excel(.xlsx / .xlsm / .xls)・字幕(.vtt / .srt)・HTML・テキスト(.txt / .md / .csv など)に対応しています。
**PDFは読めません。** 元のWordやテキストを添付してください(読めない形式のときは、その場で理由と直し方をお返しします)。

添付して、次のように頼んでください。

- 「決定事項と宿題をまとめて」
- 「決まったことを一覧にして」

## 出てくるもの

Excelが1つできます。列は次のとおりです。

| 列 | 中身 |
|---|---|
| 種別 | 決定 / 宿題 |
| 内容 | 決まったこと・やること |
| 担当 | 発言に書かれていれば担当者。**書かれていなければ「要確認」** |
| 期限 | 発言に書かれていれば期限。**書かれていなければ「要確認」** |
| 根拠(行) | 元の文字起こしの何行目か |
| 根拠の発言 | その行の発言そのもの |

**根拠の列が必ず入ります。** 一覧だけを見て信じるのではなく、
元の発言と突き合わせて確認できるようにするためです。

## ローカルLLMの使い方

抜き出しにはローカルLLM(gemma4:26b)を使いますが、**その答えを信用しません。**

1. LLMに候補と「根拠になった発言」を挙げさせる
2. その発言が**本当に文字起こしにあるか**を機械で照合する。無ければ捨てる
3. 担当・期限は、**その発言に書かれている場合だけ**採用する
4. 内容に、根拠の発言に無い数値が混じっていたら捨てる

捨てた候補は黙って消しません。「処理できなかったもの」として件数と理由を返します。

## このツールがしないこと

- **担当者や期限を推測して埋めません。** 書かれていなければ「要確認」のままです
- 決定でも宿題でもない議論の経緯は載せません
- 一覧の内容が正しいかどうかの最終判断はしません。**必ず人が確認してください**

LLMを使う以上、同じ入力でも結果が少し変わることがあります。
だからこそ根拠の列を必ず付けています。

## 元のファイル

**変更しません。** 読み取るだけで、結果は新しいExcelとして返します。

## 開発者向け

- `verify_items` が検証の中心です。`tests/test_main.py` は
  **作り話・数値の捏造・推測で埋めた担当**を落とせるかを、
  架空のLLM応答で確かめています(テストはLLMを呼びません)
- 受入時のスモークでは**本物のLLM**を1往復します。
  そこで見るのはLLMの答えの良し悪しではなく、一連の流れが通るかどうかです
- 抽出できる項目が0件でも、見出しだけのExcelを返します
  (何も返さないと、失敗したのか0件なのか分からないため)

固めて持ち込む形にするには:

```
python tools/toolpack_pack.py tool-packages/decision_extract
```
