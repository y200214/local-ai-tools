# local-ai-tools

院内PCで、文章処理やExcelの業務を助けるツールです。
院内での処理はインターネットに接続せずに行えます。
新しいツールは、ZIPファイルを持ち込んで管理画面から追加できます。

## 新しいツールを追加する

オンラインAI(Chat GPT、Claud等)へ、このリポジトリと欲しい機能を伝えます。例えば、次のように依頼できます。

```text
以下のリポジトリの制作ルールと追加ツール仕様を読み、追加ツールを作ってください。
https://github.com/y200214/local-ai-tools

表示名：文字数チェック
ID：my_text_count
機能：TXTファイル1つを読み、行数と文字数を返す。
LLM・インターネット通信は使わず、元ファイルは変更しない。

完成したZIPをダウンロードできる形で渡してください。
既存コードの変更やPR作成は不要です。
```

患者情報・実際の会議内容・秘密情報をオンラインAIやGitHubへ渡さないでください。
試験には架空のデータを使います。

完成したファイルは、次の手順で取り込みます。

1. オンライン側でZIPをダウンロードし、USB等で院内PCへ運びます。
2. 院内PCで「追加ツールの管理.cmd」を開きます。
3. 「ツールを追加...」から、ZIPを展開せずに選びます。
4. 検査・登録の完了を確認し、Open WebUIのモデル一覧から使います。

旧形式の `.localtool` も同じ画面で受け付けます。
新しく追加したモデルは「未承認」として表示されます。未承認でも全員が利用できます。
正式承認は院内の管理画面で別に扱います。検査合格と正式承認は別です。

## 以前のツールを使う・整理する

- 「前の版へ戻す...」では、保存済みの版をドロップダウンから選べます。
- 「登録を外す」はモデルの登録だけを外し、保存ファイルは残します。
- 「保存済みのツール」から、未登録のツールと版を選んで再登録できます。再検査後、未承認として登録されます。
- 不要なものはチェックを付け、「チェックしたツールを完全削除...」で対象を確認して削除できます。
  完全削除は元に戻せません。再登録したい場合に備えて、必要なZIPはUSB等へ残してください。

## うまく動かないとき

- 管理画面の「自己診断」を押し、表示された対処を確認してください。
- 追加に失敗したら、失敗した段階・原因・対処を確認してください。
- 接続エラーの場合は、Open WebUIと院内のローカルサービスが動いているかを確認します。
- 解決しない場合は、本文や秘密情報を含めず、エラーメッセージを管理担当者へ伝えてください。
